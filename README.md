\## Windows Setup Instructions



1\. Install Git for Windows.



2\. Open Git Bash.



3\. Configure your Git username and email.



4\. Clone the shared GitHub repository.



5\. Create a feature branch.



6\. Edit your assigned project file.



7\. Stage and commit your changes.



8\. Push your feature branch to GitHub.



9\. Open a pull request.



10\. Request a peer review before merging.



\## Common Git Commands



\- git status - Displays repository status.



\- git add - Stages file changes.



\- git commit - Records changes.



\- git push - Uploads commits to GitHub.



\- git pull - Downloads and integrates changes.



\- git branch - Displays local branches.



\- git switch - Changes the current branch.



\## Collaboration Guidelines



Each group member must contribute using a



separate feature branch and submit a pull



request for peer review before merging.
